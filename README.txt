# Trading Landing Page

موقع Landing Page عربي بتصميم Dark/Luxury مستوحى من هيكل مواقع منصات التداول.

## التشغيل
افتح `index.html` مباشرة في المتصفح، أو ارفعه على أي استضافة Static.

## تغيير الروابط
افتح `config.js` وعدّل:
- `telegram`
- أسعار الباقات
- النصوص
- الإحصائيات
- بيانات الكورس

لا تحتاج لتعديل `index.html` أو `script.js`.

## ملاحظة
القيم الموجودة مجرد بيانات تجريبية. استبدلها ببياناتك الحقيقية، وتجنب عرض أرباح مضمونة أو ادعاءات غير موثقة.
